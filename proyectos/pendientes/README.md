# Solicitudes de imágenes AR

Sube aquí los archivos JSON creados en `public/prototipo-ar/preparar-imagen.html`.

Cada archivo de nombre único (`<id>-<fecha>.json`) activará automáticamente el flujo de publicación de la rama de desarrollo, que incorporará el nuevo cuadro al catálogo sin borrar los anteriores, extraerá imágenes a carpetas, optimizará sus capas y generará `targets.mind`.

**No pongas datos privados:** el repositorio es público. Para enviar los archivos debes iniciar sesión en GitHub con permisos de escritura. No se deben poner tokens de GitHub en las páginas web.
