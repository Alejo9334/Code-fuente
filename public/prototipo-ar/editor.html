Propiedades de la capa —

Animación independiente

Trabaja en un solo lugar: selecciona la referencia impresa, crea capas PNG, configura sus animaciones y genera el archivo de publicación del cuadro activo. El enlace de los clientes sigue siendo solamente el visor AR. Descarga un respaldo JSON antes de cerrar; el proyecto local no se sincroniza automáticamente entre equipos.

Nuevo cuadro AR

Registra una imagen única para el reconocimiento y al menos una capa PNG con transparencia.

Las capas deben tener la misma relación de aspecto que la imagen final. Se guardarán en tu borrador local; no se publican automáticamente.

Publicar nuevo cuadro en GitHub

El editor generará un solo archivo de publicación con la imagen de referencia, las capas PNG y los ajustes actuales. No se necesitan carpetas manuales ni contraseñas en este panel.

Solo puedes agregar cuadros nuevos por este flujo. Si el ID ya existe en el visor publicado, no sobrescribiremos su contenido. La publicación se confirma en GitHub con una cuenta autorizada.

Selecciona el cuadro y prepara su paquete.
Abrir GitHub para subir el JSON

En GitHub, sube el JSON descargado a la carpeta proyectos/pendientes/ de la rama de desarrollo y confirma «Commit changes». El flujo automático compilará el reconocimiento y optimizará las imágenes. La vista Preview se actualizará tras su despliegue.

Probar el cuadro en tu celular

Escanea este QR con la cámara del teléfono. Se abrirá el visor AR con los ajustes del cuadro seleccionado, siempre que sus archivos ya estén publicados en GitHub.

También puedes copiar el enlace para enviártelo por WhatsApp.
