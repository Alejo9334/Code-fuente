Prepara tu próxima imagen AR

Selecciona la imagen física que reconocerá la cámara y sus capas PNG transparentes. Este panel organizará todo en un único proyecto listo para publicar en GitHub, sin crear carpetas manualmente.

1. Identificación de la imagen

Usa una fotografía nítida del diseño físico, sin marcos ni reflejos. Archivo máximo: 8 MB.

La referencia aparecerá aquí

2. Capas transparentes

Agrega las capas en orden de atrás hacia delante. Puedes moverlas y definir su profundidad o animación antes de generar el proyecto.

No has agregado capas.

3. Crear paquete de publicación

Se generará un archivo JSON que contiene las imágenes y sus parámetros. Al subir ese único archivo a GitHub, el sistema creará la carpeta del diseño, optimizará las capas y compilará el reconocimiento automáticamente.

Completa el nombre, la referencia y al menos una capa.

Abrir GitHub para subir el archivo

En GitHub, selecciona el archivo recién descargado y pulsa «Commit changes» en la rama desarrollo/multicuadros-ar-v2. El flujo automático se ejecutará al confirmar.

Así se publica

  1. Escoges una imagen física.
  2. Subes las capas PNG y ajustas sus efectos.
  3. Generas un archivo de publicación.
  4. Lo subes con tu sesión de GitHub.
  5. GitHub prepara los archivos optimizados y los agrega al catálogo.
Seguridad: este panel prepara un proyecto localmente en tu navegador. No solicita contraseñas ni tokens de GitHub. La publicación requiere iniciar sesión en GitHub y tener permiso de escritura sobre la rama de desarrollo. El archivo subido y sus imágenes serán públicos en el repositorio.

Recomendaciones

Referencia: imagen bien iluminada, con detalles claros, sin superficies reflectantes.

Capas: PNG transparentes de tamaño consistente para evitar desplazamientos en AR.

Por proyecto: máximo 15 capas, 8 MB por imagen y 24 MB en el archivo JSON. El catálogo admite hasta 30 diseños.

Si GitHub no permite subir el archivo a esa carpeta directamente, abre la carpeta de solicitudes y elige «Add file → Upload files».
